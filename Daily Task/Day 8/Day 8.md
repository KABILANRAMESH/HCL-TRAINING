# Day 8 – Collections Framework Part 2

## Objective
To learn Map implementations, employee sorting, Comparators, and the equals/hashCode contract.

## Concepts Covered
- **HashMap:** Stores employees using employee ID as the key for fast lookup.
- **LinkedHashMap:** Maintains insertion order.
- **TreeMap:** Stores department reports in sorted key order.
- **Map.merge():** Counts department visits and employees.
- **Comparable:** Sorts employees naturally by employee ID.
- **Comparator:** Sorts employees by salary in descending order, with name as a tie-breaker.
- **Top 5 Salaries:** Displays the five highest-paid employees.
- **equals() and hashCode():** Uses employee ID to define equality and generate consistent hash codes.
- **HashSet:** Prevents duplicate equal Employee objects.

## Implementation
Created `EmployeeDirectory.java` with employee lookup, department reports, frequency counting, sorting, top-five salary ranking, and equality demonstration.

## Outcome
Practiced Java Collections Framework Part 2 concepts through an employee directory example.
