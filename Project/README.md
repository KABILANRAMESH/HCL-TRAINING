# Hospital OPD & Appointment Management System

## Project Description

A platform for a multi-specialty hospital to manage doctor schedules,
patient registration, OPD appointment booking, consultation notes and billing.

## User Roles

- Admin
- Doctor
- Receptionist
- Patient

## Main Modules

- Authentication & User Management
- Doctor & Schedule Management
- Appointment & OPD Queue
- Consultation & Prescription
- Billing & Invoicing
- Notifications & Reports

## Technologies

- Java
- Spring Boot
- MySQL
- React
- Git & GitHub
